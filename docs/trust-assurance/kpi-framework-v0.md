# Product / Customer KPI Framework V0

M17.5-S4 defines what may be counted and how uncertainty must be retained. It supplies no evaluator and no KPI execution results. PRODUCT describes repository metadata; TENANT describes one future authorized customer scope. All six tenant definitions are DEFINITION_ONLY.

Requirement with evidence != requirement satisfied != compliant. Governed decision count != decision quality or sufficiency. UNKNOWN != 0, false or NOT_APPLICABLE. Unknown currency is never STALE.

PRODUCT_DOCUMENTARY_ONLY means an offline documentary predicate is specified; it is not an operationally executable service. Every definition below carries its population, grain, sources, predicate, temporal coordinates, uncertainty and lineage. The shared named rules are normative components of each referencing definition. The JSON is the canonical metadata; this complete rendering is parity-checked.
