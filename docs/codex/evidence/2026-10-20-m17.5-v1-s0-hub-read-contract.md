## Contract boundaries

PRODUCT_ASSURANCE uses pinned repository/product metadata with no tenant;
TENANT_ASSURANCE requires exactly one verified organisation, immutable manifest
and every typed authorized read hop. No shared totals, silent mode conversion,
legacy name joins or tenant edits to product claims.

The SCOPE_V1-derived manifest fixes intended use/audience, framework editions,
explicit-reference-set versus full-framework population, exact governed subject
set/rule, allowed source connections, evidence source versions, effective_at,
recorded_cutoff, current access context, acquisition completeness, exclusions,
limitations and UNKNOWN conditions. It is metadata, not a canonical object.
Complete means complete for this manifest, never a whole customer estate.

The temporal contract requires exact source/state/decision/policy/resolver pins,
both explicit upstream-precision time coordinates and one proven consistent
snapshot across mutable dependencies. Matching timestamps alone are insufficient.
External inputs must be immutable version-pinned references. Missing atomicity
yields NON_ATOMIC/UNKNOWN, not a combined tenant result. generated_at is separate.
Restatement/supersession appends a new projection and retains historical truth.
Historical reads still require current access; disposable caches bind mode,
tenant, scope, source versions, time coordinates and access context.

UNKNOWN, NOT_MAPPED, NOT_APPLICABLE, NOT_ASSESSED, INSUFFICIENT_EVIDENCE,
SOURCE_PENDING, ACCESS_DENIED, PARTIAL_ACQUISITION, DEPENDENCY_INVALID and
NOT_ASSERTED each have explicit rendering semantics. Denial never means absence;
unavailable population never means zero; empty never means compliant/green.
MAPPED != satisfied and evidence availability != sufficiency.

Exposure levels are separate from truth, record access and affirmative claim
use. All six evaluated levels have audience/data/publication/review boundaries;
**no exposure level is granted**. The 38 S2 ceilings control; all 42 claims remain
INELIGIBLE / INTERNAL_ONLY / PROHIBITED. S1 alignment candidates stay historical
mapping metadata, never publication ceilings. The 61 OPEN historical S2 gaps
and 14 known E1 exposure members remain separate populations; the latter is an
open universe and L04 package expansion is not an extra member.

Certification/attestation stays NOT_ASSERTED, with zero external artifacts in
the pack. Positive state requires independently issued authenticated issuer,
subject, framework/version, exact scope, validity, artifact identity,
verification and expiry/revocation basis. No inferred certification or awards.

The European Assurance Profile separates source/version, applicability,
mapping, evidence availability, sufficiency, internal readiness and external
artifact axes. Original OJ base text does not establish current operative law.
Qualified source/current-law/applicability review remains required; those
unestablished axes stay UNKNOWN. No generic EU AI Act compliant state exists.
