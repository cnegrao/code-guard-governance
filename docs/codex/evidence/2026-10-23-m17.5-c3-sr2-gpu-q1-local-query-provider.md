## Transport, privacy and admission

Host is a code constant `127.0.0.1`; only port is configurable, default 8765. The live smoke used ephemeral port 54451. Four active handlers, listen backlog four, two-second socket I/O timeout and a single nonblocking inference lock bound resource admission. Busy/unready inference returns generic 503; excess TCP connections are closed without a new handler or an application queue. Normal rejected bodies are bounded/drained so Windows delivers generic HTTP errors reliably.

`GOVIA_SEMANTIC_GPU_TOKEN` must be present with 43–128 ASCII base64url/hex-compatible characters; operators generate at least 32 random bytes. The manifest and tracked code contain no operational secret/default token. Requests use a dedicated header and constant-time comparison. Missing/bad request token returns generic 401. It grants local transport access only.

The entire Node request body is constructed as `{question}`. The real HTTP contract test captures that object exactly and checks the token header plus absence of Authorization/Cookie. The Python parser independently rejects additional fields, duplicate keys, invalid JSON/UTF-8, blank/non-string input and questions over 8192 UTF-8 bytes. The live service rejected an extra synthetic `tenant` field with 400, and admitted actual Node requests through that same closed schema. No principal/session/organisation/user/roles/credential epoch, retrieval results or database/Supabase credentials are transmitted. The smoke child receives an explicit OS/runtime environment allowlist rather than the parent's full environment. No question/token logging or query persistence.

Response has exactly `space`, `query_recipe`, `vector`; space has exactly five fields. No confidence, similarity, classification, principal data, path or GPU diagnostic is present. Health is separate, bounded and redacted, with independent process/model/CUDA flags and exact identity/FP32.

The Node constructor accepts only literal `http://127.0.0.1:<port>` with no credentials/path/query/fragment. Native HTTP uses literal IPv4 and `agent:false`: no DNS, proxy agent, redirects or remote endpoint. It bounds response headers to 8192 bytes and body to 32768 bytes, decodes UTF-8 strictly and rejects malformed/non-closed/duplicate-key JSON and unsupported encodings. AbortSignal cancels requests and body reads; a five-second transport deadline does not replace or weaken the existing source's five-second deadline.

`createQueryEmbeddingSource` remains unchanged and owns exact space/recipe/model-version equality plus finite, nonzero, FP32-representable and exact-dimension vector admission. The adapter supplies an unadmitted envelope; only this existing source constructs its immutable privately admitted query identity. No SQL retrieval adapter change. HTTP cancellation does not preempt an active CUDA kernel; the single inference lock stays held until completion and subsequent requests fail busy rather than queue.
