- `apps/dashboard/repositories/talk.ts:semanticSearch` calls `db.write.rpc("agent_semantic_search", ...)` with `p_organisation_id` from the verified principal's organisation.

It filters `ae.organisation_id = p_organisation_id`, joins agents only on `a.agent_id = ae.agent_id`, and joins owners only on `u.user_id = a.owner_user_id`. It does not constrain the agent organisation to the requested organisation.
- `supabase/migrations/20260818004053_agent_registry_graph_part_3.sql:5–6` declares independent foreign keys for `agent_embeddings.agent_id` and `organisation_id`. They do not enforce a shared organisation between the embedding and agent. The tracked migration references to `agent_embeddings` contain no later composite tenant constraint or correcting trigger.

This is a code/schema finding, **not** a claim that such a row exists or that a hosted leak occurred. No hosted inspection or database execution was performed.
