## Three corrected architecture blockers

1. **Plural facets:** one optional collection commitment per kind and projection. Seven typed plural families accept 0–20 independently grounded items, with stable natural-key hashes and sorted collection fingerprints. Duplicate natural keys fail even when descriptive payload changes. TECHNICAL_SUMMARY remains exactly one item when admitted. Tests store multiple dependencies and multiple entrypoints under the same subject/projection.
2. **Source identity versus handling:** source-only manifests contain no mutable eligibility/admission state. Immutable evaluation rows carry recipe/profile/result/capture provenance. A later admitted V2 evaluation preserves repository/snapshot/entry/locator/subject/set IDs, changes admission basis/event identity and produces a new projection when handling/content changes. Reevaluating an identical basis retains semantic projection identity while its historical exact event seal remains immutable.
3. **Bounded summary sources:** explicit set roots and relational membership commit 1–20 same-snapshot leaf subjects, selector/scope/anchor, count and order-independent membership fingerprint. Completeness means complete declared selection. ENTIRE_SNAPSHOT_MANIFEST separately requires exact relational manifest equality. Two legitimate sets and summaries in one snapshot remain distinct; no path-prefix completeness inference is used.
