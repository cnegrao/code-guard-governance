## Public contract before/after

Agent before: list/create/update serialized DB rows as Agent; detail returned raw `agent`, owner metadata, `compliance`, `compliance_score`, `compliance_gaps`. Raw rows could include `cg_ag_*` and hidden `external_refs.controlStates`.
Agent after: public `Agent` is operational inventory only. `AgentRecord` is the internal persisted row. `lib/legacy-control-dto.ts:AGENT_PUBLIC_FIELDS` and `projectAgent` explicitly copy 27 allowed fields. List/POST/PUT serialize only this projection. Detail returns `{ agent: Agent, owner_name, owner_email, ...LegacyControlEnvelope }`.

System before: list/create/update serialized AISystem DB rows including `cg_sys_*` and `external_refs`; detail added `compliance`, `compliance_score`, `compliance_gaps`.
System after: public `AISystem` is an allowlisted 38-field inventory record; `AISystemRecord` is storage-only. `SYSTEM_PUBLIC_FIELDS` and `projectSystem` sanitize all read/create/update results. Detail returns `{ system: AISystem, owner_name, owner_email, agent_count, ...LegacyControlEnvelope }`. The detail caller now reads owner/count from the actual wrapper.

Both public types remove aggregate members. `AgentDetail` and `SystemDetail` express the actual wrapper plus legacy envelope. Negative compile-time checks reject raw cg flags, external_refs and scores. Unknown future DB columns cannot enter the public DTO automatically. No known active local caller needs the removed aliases or base external_refs; no external/hosted client dependency was identified.

Raw `cg_ag_*` / `cg_sys_*`: retained in the database/repository storage types; never copied into base public objects. Existing boolean fallback becomes a recorded source state only inside the envelope. `external_refs` is omitted entirely from both base public DTOs, including nested controlStates; storage and unrelated references are preserved. Manual states are not duplicated under any alias.

Closed detail/PATCH envelope (`lib/legacy-control-dto.ts:LegacyControlEnvelope`, `legacyControlEnvelope`):

```json
{
  "legacy_control_authority": "LEGACY_NON_AUTHORITATIVE",
  "legacy_control_limitation": "Legacy/manual records - not a compliance or assurance determination.",
  "legacy_control_states": { "cg_ag_001_registered": "passed" },
  "legacy_control_gaps": []
}
```

PATCH returns exactly these four fields. No compliance/score/coverage/readiness alias remains. Stored `not_assessed`, `passed`, `failed`, `waived` vocabulary and the repository update mapping remain unchanged: passed/waived -> legacy boolean true; failed/not_assessed -> false; exact recorded source state remains in external_refs.controlStates. Tests exercise the real repository writes through a mocked HTTP transport, preserving unrelated refs. This is not a live DB persistence claim.

Removed calculation paths: both services' `computeScore`, AgentTable `compliancePct` / `complianceColor`, home `cColor`, dashboard `computeCompliance`, `computeCgSysComplianceRate`, `computeEvidenceCoverage`. They are deleted, not calculated and hidden. Underlying graph fields are unchanged. The duplicate Agent detail gap RPC is removed; dashboard retains only two legacy gap RPC reads (count/list), not the former third percentage read. Graph work solely for the two removed ratio functions is gone; other LX03 graph-derived count consumers remain.

Dashboard before: `complianceRate`, `cgSysComplianceRate`, `evidenceCoverage`, `totalGovernanceGaps`, `topGaps`.
Dashboard after: first three removed with no aliases or replacement denominator; latter two explicitly become `totalLegacyControlGaps` / `legacyControlGaps`, with `legacyControlAuthority` and `legacyControlLimitation`. These are bounded legacy record counts/list entries, not attainment metrics. Gap rows copy only agent_code, agent_name, risk_level, total_gaps, owner_name. Other summary fields remain operational inventory.
