## Exact space, selection, retrieval and limits

Compatibility is case-sensitive equality of projection schema/provider/model/model version/dimension, without aliases. Materialized compatible rows precede vector arithmetic; actual dimension and nonzero finite norms are rechecked. Query rejects empty identity, zero/nonfinite/wrong-size vectors. Native pgvector rejects NaN/Infinity at input (22000). No padding, truncation, ANN, new HNSW/IVFFlat index or cross-space fallback.

`LATEST_RECORDED_IN_EXACT_SPACE_V1`: tenant/space first; group by subject family/actual kind/ID; select by generated_at DESC, created_at DESC, representation_id COLLATE C ASC before cosine. Nonfinite/future generation/record times fail acquisition. Historical duplicates cannot consume top-K. Newest unsupported rows do not fall back to older support. Candidate/canonical IDs remain distinct. Both timestamps and the fingerprint tuple are returned; freshness stays UNKNOWN and never certifies source/governance state.

Exact cosine runs only over materialized valid selected rows. Threshold is inclusive in [-1,1], policy `EXACT_COSINE_V1`; stable relevance then subject/representation ordering; trusted explicit limit 1..20. Public output carries rank, algorithm/selection policy and BOUNDED_RECORDED_REPRESENTATIONS_ONLY coverage, with no numeric similarity/confidence.

Bounds: question ≤8192 UTF-8 bytes; scalar/identity metadata ≤512 UTF-8 bytes; query dimension 1..16000; scan reads at most 10001 compatible versions and rejects >10000; complete selected support ≤100 assertion/evidence refs per hit; response ≤262144 bytes. Exceeding a bound is explicit unavailability, never a truncated population/provenance presented as complete. No cursor or performance/capacity claim.

The server adapter begins READ COMMITTED on a server-owned SQL connection and sets transaction-local statement_timeout=5s and lock_timeout=5s **before** the single parameterized RPC SELECT. It commits/rolls back and releases; failed rollback destroys the connection. The RPC refuses unset or over-5s request deadlines (`EXECUTION_BUDGET_REQUIRED`). A real waiting-query cancellation test proves interruption; this is not a function-local timeout claim. No pool/provider is operationally activated by the factory.
