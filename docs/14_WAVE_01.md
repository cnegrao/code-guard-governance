# WAVE 01 — Sellable Controlled Pilot — V4 FINAL

## Goal
Make the existing Gov IA demonstrable and sellable in a controlled environment without adding unnecessary infrastructure.

## P0 — Freeze baseline and protect work
1. Keep `origin` as the user's fork/source of truth.
2. Keep Dênio `upstream` read-only; do not push or wholesale-merge.
3. Install V4 FINAL docs in the user repo and commit documentation baseline first.
4. Resolve/freeze CG-AG v1 taxonomy in documentation before external publication.
5. Validate current auth/tenant isolation path; no public production/real customer data with DEV service-role bypass.

## P1 — Repair the existing core flow
1. Fix Agent create `owner_user_id` mismatch securely by deriving/validating authenticated owner server-side.
2. Validate create → list → detail/Passport.
3. Fix role persistence/login consistency.
4. Correct organisation metadata such as industry/country where needed.
5. Ensure empty-universe metrics do not show misleading `100% compliance`; return N/A/Not Assessed where appropriate.

## P2 — Reuse and integrate repository Discovery
1. Review/copy reusable repository connectors and scanner components deliberately from Dênio upstream.
2. Preserve current providers: GitHub, GitLab, Azure DevOps, Bitbucket, Gitea, Forgejo.
3. Define 3NF Discovery Run / Source / Finding / Evidence persistence against existing schema.
4. Scan one controlled repository end-to-end.
5. Persist candidate-agent findings with source, commit/path, detector, evidence, confidence and trust state.
6. Promote a validated candidate to registered Agent/Passport.

## P3 — Agent Passport MVP
Expose identity/lifecycle, discovery/provenance, ownership, business context, model/provider, tools/MCP/resources, data assets, privacy classifications, capabilities/permission/authorization state, policies/controls/risks/evidence, relationships and custom metadata.

## P4 — Privacy v1
Start from Dênio lexical scanner, but evolve toward structured findings. Add safe value-pattern/checksum support for selected types and explicit detector/evidence fields; do not block MVP on full semantic AI classification.

## P5 — Metrics v1
Central metrics service with an initial governance catalog. Persist raw/historical facts; calculate scores/rates on demand. Materialization only if performance requires it.

## Exit criterion
Controlled demo proves:
`Repository → Discovery → Candidate Agent → Agent Passport → Governance Findings → Decision/HITL → Evidence → Calculated Metrics → Governance Center`
