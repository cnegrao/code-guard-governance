# CG-AG v1 Baseline — Freeze Rule

The public `cg-ag` v1 control IDs and meanings must not be silently repurposed.

Known v1 baseline:
1. Agent Inventory
2. Agent Owner
3. Model Registration
4. Tool Authorisation
5. Prompt Governance
6. MCP Server Governance
7. Human Oversight
8. Audit Trail
9. Data Governance
10. Risk Classification
11. Agent-to-Agent Governance
12. Autonomous Governance

## Drift to resolve before publication
The CodeGuard README, traceability matrix and newer visual/dashboard language use different mappings for 001–012. Treat this as documentation/framework drift, not as permission to silently overwrite v1 semantics.

New ideas such as Circuit Breaker, FinOps, Third-Party AI and Board Scorecards should be additive capabilities/controls or part of an explicitly versioned future framework.
